📡 Proyecto Infraestructura Tecnológica

Virtualización + Docker + Kubernetes

🎯 Objetivo del Proyecto

Construir y documentar una infraestructura tecnológica básica que integre máquinas virtuales Linux, contenedores Docker con servicios esenciales en comunicación, y orquestación con Kubernetes Minikube.

✅ Tecnologías utilizadas

  • VirtualBox - Ubuntu 24.04 LTS / Debian 13.5
  • Docker Engine - Docker Compose
  • Kubernetes - Minikube
  • Nginx + Python HTTP Server

📊 Valoración

  • Componente 1: Virtualización (30%)
  • Componente 2: Contenedores Docker (30%)
  • Componente 3: Orquestación Kubernetes (20%)
  • Componente 4: Documentación (10%)

💻 Componente 1: Virtualización con Linux

Valoración: 30% | Estado: ✅ Completado

📋 Actividades realizadas

  • Instalación de 2 máquinas virtuales con VirtualBox
  • VM1: Ubuntu 24.04 LTS (entorno gráfico)
  • VM2: Debian 13.5 (solo consola)
  • Particionamiento manual: 3 particiones (/, swap, /home) en ambas VMs
  • Configuración de red interna (modo Red Interna - intnet)
  • Configuración y verificación de acceso SSH desde VM1 a VM2

🔧 Comandos principales

# Asignar IP estática en Ubuntu
sudo ip addr add 192.168.100.10/24 dev enp0s3

# Asignar IP estática en Debian
sudo ip addr add 192.168.100.20/24 dev enp0s3

# Verificar IPs
ip a | grep 192.168.100

# Probar conectividad (ping)
ping 192.168.100.20

# Conexión SSH desde Ubuntu hacia Debian
ssh debian@192.168.100.20

🐳 Componente 2: Contenedores Docker

Valoración: 30% | Estado: ✅ Completado

📋 Actividades realizadas

  • Instalación de Docker Engine en Ubuntu 24.04
  • Creación de Dockerfiles propios basados en ubuntu:24.04
  • Frontend: Servidor web Nginx con archivos HTML estáticos
  • Backend: Servidor HTTP simple en Python (puerto 5000)
  • Orquestación con docker-compose.yml
  • Configuración de volúmenes persistentes para archivos HTML

📁 Estructura del proyecto

proyecto-docker/
├── frontend/
│   ├── Dockerfile
│   └── index.html
├── backend/

docker-compose.yml

backend/Dockerfile

🔧 Comandos principales

# Construir y levantar los contenedores
cd ~/proyecto-docker
docker compose up -d

# Verificar contenedores activos
docker ps

# Acceder al frontend (Nginx)
http://localhost:8080

# Acceder al backend (Python)
http://localhost:5000

# Detener contenedores
docker compose down
