Frontend funcionando con Docker

Objetivo: Construir y documentar una infraestrucuta tecnologica basica que integre maquinas virtuales linux, contenedores dockler con serviciones esenciales en comunicacion y orquestacion con kubernetes Minikube.

Tecnologias utilizadas

  • Docker Engine + Docker Compose
  • Virtuabox - Ubuntu 24.04 / Debian 13.5
  • Kubernestes Minikube
  • Nginx + Python HTTP Server
